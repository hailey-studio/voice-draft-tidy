# 完整示例

下面的稿子都是**为演示虚构的**，模仿真实语音输入的样子：有识别错别字、车轱辘话、重点埋在中间。分析部分展示整理者应该怎么做。

示例 1 走完两步，看清“整理到什么程度”。示例 2 只做第一步，展示识别错误很多的稿子怎么处理。

---

## 示例 1：为什么我不再逼自己早起

### 原始语音稿

> 最近刷到好多人在晒五点起床的vlog，然后我就跟风也试了一个月，结果我发现我根本不是那块料，每天五点闹钟响我就是在床上跟自己打架，起来之后整个上午都是蒙的，然后效率反而更低了，我当时就在想是不是我太懒了，自律的人都能做到为什么我做不到，然后就开始自我怀疑，就是那种很焦虑的感觉。
>
> 然后有一天我睡到八点，那天我反而特别有精神，写东西特别顺，我才意识到可能问题不在于几点起，而在于我有没有睡够，就是每个人的生物中不一样嘛，有的人就是城型人有的人就是夜猫子，这个其实是有研究的，好像说有百分之三十的人是夜猫子我记不清了。
>
> 然后我觉得社交媒体上那种早起就等于自律等于成功的续事很有问题，因为他把一个工具变成了一个道德标准，你没做到你就是不够努力，然后其实很多晒早起的人他晚上九点就睡了，他们只是没拍晚上那部分。
>
> 所以我现在的做法就是，我不再定五点的闹钟了，我就是保证睡够七个半小时，然后把最重要的事情放在我自己精神最好的那个时间段，对我来说是上午十点到十二点。我觉得早起这件事吧，他本身没有错，错的是我们把别人的作息当成了自己的标准。
>
> 然后还有就是我发现那一个月我其实也不是完全没有收获，至少我知道了我不是城型人，这个也挺重要的吧，了解自己。就是说你可以试，但是试完了不适合就放下，不要硬称，不要觉得放下就是失败，放下不是失败。

### 第一步输出（提炼和讨论，不改稿）

**一句话中心**
早起本身没有错，错的是把别人的作息当成自己的标准。
出自原句：「我觉得早起这件事吧，他本身没有错，错的是我们把别人的作息当成了自己的标准。」

另一个候选是最后一段的「试了不适合就放下，放下不是失败」。两句在抢位置。我倾向于让第一句当中心，因为它能解释你整个经历；第二句更适合当结尾给观众的行动建议。

**逻辑线**
跟风早起一个月 → 效率更低、自我怀疑 → 某天睡到八点反而状态好 → 问题是睡没睡够，生物钟因人而异 → 【跳】批评社交媒体的早起叙事 → 我现在的做法 → 中心句 → 【绕回】那一个月也有收获 → 试了不适合就放下

**问题清单**
- 「百分之三十的人是夜猫子」你自己说记不清了，发出去之前要么查实，要么删掉，不然评论区会追问来源。
- 批评社交媒体那段放在「我现在的做法」前面，读起来像从个人经历突然跳到了评论。可以考虑挪到中心句后面，作为“为什么我们会拿别人的作息当标准”的解释。
- 「不要觉得放下就是失败，放下不是失败」是车轱辘话，留一句就够。
- 「他们只是没拍晚上那部分」这句很好，有画面又有点幽默，现在埋在段落中间，可惜了。

**待确认词（原文 → 我的理解）**
蒙 → 懵｜生物中 → 生物钟｜城型人 → 晨型人｜续事 → 叙事｜硬称 → 硬撑｜他（指早起这件事）→ 它

**我的看法**
最打动人的是开头「每天五点闹钟响我就是在床上跟自己打架」和中间「睡到八点那天反而特别有精神」的对比，很多人有同感。最弱的是那个记不清的数据。

**问你**
1. 你最想让看完的人带走的是「别拿别人的作息当标准」，还是「试了不适合就放下」？
2. 那一个月里，有没有哪一天让你特别崩溃？有的话，可以作为开头的钩子。

### 第二步输出（假设作者回复：中心选第一个，数据删掉，没有更具体的崩溃瞬间）

【开头钩子】
最近刷到好多人在晒五点起床的vlog，然后我就跟风也试了一个月，结果我发现我根本不是那块料，每天五点闹钟响我就是在床上跟自己打架，起来之后整个上午都是懵的，然后效率反而更低了。

【自我怀疑】
我当时就在想是不是我太懒了，自律的人都能做到为什么我做不到，然后就开始自我怀疑，就是那种很焦虑的感觉。

【转折】
然后有一天我睡到八点，那天我反而特别有精神，写东西特别顺，我才意识到可能问题不在于几点起，而在于我有没有睡够，就是每个人的生物钟不一样嘛，有的人就是晨型人有的人就是夜猫子。

【观点】
我觉得早起这件事吧，它本身没有错，错的是我们把别人的作息当成了自己的标准。

社交媒体上那种早起就等于自律等于成功的叙事很有问题，因为它把一个工具变成了一个道德标准，你没做到你就是不够努力。然后其实很多晒早起的人他晚上九点就睡了，他们只是没拍晚上那部分。

【我现在的做法】
所以我现在不再定五点的闹钟了，我就是保证睡够七个半小时，然后把最重要的事情放在我自己精神最好的那个时间段，对我来说是上午十点到十二点。

【结尾】
那一个月我其实也不是完全没有收获，至少我知道了我不是晨型人，这个也挺重要的吧，了解自己。【这里可以补一句：你想对正在硬撑早起的人说什么】就是说你可以试，但是试完了不适合就放下，不要硬撑，放下不是失败。

**改动说明**
- 挪动：批评社交媒体那段从中心句前面挪到了后面，作为对观点的解释。
- 删除：「这个其实是有研究的，好像说有百分之三十的人是夜猫子我记不清了」，按作者要求删掉。
- 合并：「不要觉得放下就是失败，放下不是失败」合成「放下不是失败」。
- 修正：识别错误按待确认词表改了，「然后我觉得」开头的“然后”删了一个，其余口头禅都保留。
- 待补：结尾留了一个【】，如果不想补，直接删掉提示就行。

注意整理者没有做的事：没有加新的例子，没有改写任何句子的说法，没有加金句收尾，没有把“我觉得”改成肯定的语气。

## 示例 2：识别错误很多的稿子，只做第一步

### 原始语音稿

> 就是我实习了三个月我发现开会这件事真的是很神奇，就是很多会它其实是不需要开的，大家坐在那里一个小时最后结论就是下次再说，然后我一开始觉得是我自己没有经验看不懂，后来我发现其实老员工也觉得很浪费时间但是没人说出来，就是一种集体的沉默吧，然后我就在想为什么会这样，可能是因为开会它给人一种在工作的感觉，就是一种表演性的忙碌，你在会上你就是在工作，你不在会上你就不知道在干嘛，然后我觉得这跟学校其实挺像的，学校里面小组作业也是这样，开很多次会但真正干活的就那一两个人，然后我想说的是就是如果你是新人，你要学会判断哪些会是重要的，就是有没有一个明确的决策要做，有决策的会就认真听，没有决策的会你可以带着自己的活去，当然这个要看公司文化，有的公司你这样做会被认为不尊重人，所以就是要看情况吧，然后我还想说就是你自己组织会议的时候，一定要提前发议程，会后发纪要，这样别人就会觉得你很靠普。

### 第一步输出

**一句话中心**
新人要学会判断哪些会议真正有用：看它有没有一个明确的决策要做。
出自原句：「有没有一个明确的决策要做，有决策的会就认真听」

**逻辑线**
实习发现很多会不需要开 → 老员工也这么觉得但不说 → 为什么：表演性的忙碌 → 【跳】学校小组作业也这样 → 给新人的建议：按有没有决策判断 → 看公司文化 → 【新话题】自己组织会议要发议程和纪要

**问题清单**
- 前半段在“吐槽开会”，后半段在“给建议”，现在的比例是吐槽多、建议少。如果这条视频的价值在建议，前面可以压缩。
- 「学校小组作业也是这样」和主线关系不大，删掉不影响理解。也可以留着拉近学生观众，取决于你的观众是谁。
- 「带着自己的活去开会」紧接着又说「可能被认为不尊重人」，建议和风险放在一起，观众可能不知道到底该不该做。需要你给一个判断标准。
- 最后「自己组织会议」是另一个话题，可以留到下一篇。
- 「老员工也觉得浪费时间」，如果你的同事可能看到这条视频，这句要掂量一下。

**待确认词（原文 → 我的理解）**
靠普 → 靠谱｜表演性的忙碌 → 原文没错，确认这就是你想用的词？

**我的看法**
「表演性的忙碌」这个说法很准，可以考虑放进标题或开头。最弱的是建议部分缺一个具体例子。

**问你**
1. 这条视频你想让人看完带走的是“吐槽有共鸣”，还是“学会一个判断方法”？
2. 有没有一次具体的会，让你第一次意识到“这个会根本不需要开”？
